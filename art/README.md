# Графика

- `food/` — картинки еды. Часть из набора Kenney Food Kit (лицензия CC0, https://kenney.nl/assets/food-kit),
  остальные (масло, кабачок, чеснок, тимьян, сахар, ваниль) нарисованы для этой игры (svg).
- `kitchen/` — пол, стены, столы, станции, ящик и повар (svg, нарисованы для этой игры).

Чтобы заменить картинку, положи файл с тем же именем (png или svg) в эту папку.
Для ингредиентов имя картинки задаётся в `data/ingredients.json` (поля `icon` и `icons`).
